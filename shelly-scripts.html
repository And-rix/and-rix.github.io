📡 internet-watchdog.js

This script periodically check your internet connectivity. If a customized failure count reached, it will reboot the router.

  • Auto restart: Detect internet outages and reboot the connected router when necessary.
  • Customizable: You can enter your own limits.

📡 internet-watchdog-telegram.js

This script periodically check your internet connectivity. If a customized failure count reached, it will reboot the router. When internet returns - you will receive a Telegram message.

  • Auto restart: Detect internet outages and reboot the connected router when necessary.
  • Customizable: You can enter your own limits.
  • Telegram: You need to setup Botfather Telegram Bot by your own.
https://raw.githubusercontent.com/And-rix/shelly-scripts/refs/heads/main/internet-watchdog-telegram.js
